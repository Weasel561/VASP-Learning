# Day 3：查看文件内容

学习如何查看文件内容，为以后阅读 VASP 的 OUTCAR 等计算输出做准备。

## 常用命令

```bash
cat 文件名           # 显示全部内容，适合短文件
cat -n 文件名        # 显示全部内容并加行号
head -n 5 文件名     # 查看前 5 行
tail -n 5 文件名     # 查看最后 5 行
less 文件名          # 分页查看
```

## 分页查看

进入 `less` 后：

- 空格：向下翻页。
- `/关键词` 然后回车：搜索。
- `q`：退出。

## 实时查看更新

```bash
tail -f 文件名
tail -n 5 -f 文件名
```

`-f` 持续显示追加内容；第二条先显示末尾 5 行，再持续跟踪。
按 `Ctrl+C` 退出，可用于观察计算输出更新。

## 易错点

- `-n` 后面要有行数，行数和文件名之间要有空格。
- 原笔记的 `tail -nf 文件名` 写法不正确，应写成以上形式。
