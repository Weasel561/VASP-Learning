## 保存规则

- 每天一份 Markdown 文件，命名为 `day01.md`、`day02.md`，依次递增。
- 笔记直接放在 `linux/` 中，不创建同名文件夹。
- 标题、命令示例、易错点和复习重点保存在对应当天的笔记中。
- [早期测试文本](archive/test-text.md) 保留在归档目录中。

路径容易混淆时，先用 `pwd` 确认位置，再用 `ls` 核对名字。
